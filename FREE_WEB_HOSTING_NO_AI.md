# Free Browser Web Hosting & Offline Guide for RomaLingua 🏛️ (No "ai" in Domain)

This guide shows you how to host and run **RomaLingua** and **Latina Flap** live on the web for **100% free** under a domain that contains **zero "ai"** sequence or completely offline.

---

## ⚡ Method 1: Netlify Drop (10-Second Drag & Drop)

**Domain:** `https://<your-custom-name>.netlify.app`  
**Cost:** 100% Free Forever  
**Prerequisites:** None. No GitHub account, no Git, no coding required.

### Steps:
1. **Download the Web Bundle**:
   - Get `romalingua_bundle.zip` directly from the app or the repository.
   - Unzip the folder on your computer.
2. **Open Netlify Drop in your browser**:
   - Visit [app.netlify.com/drop](https://app.netlify.com/drop).
3. **Drag and Drop**:
   - Drag the unzipped folder into the browser window.
4. **Done!**:
   - Live immediately at: `https://romalingua-latin.netlify.app` (zero "ai" in domain).
